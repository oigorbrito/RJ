# Blocker register

Record only external conditions that prevent execution. A blocker never converts unexecuted work into PASS.

| blocker_id | type | blocked operation | observed evidence | impact | work that can continue | objective unblock condition |
| --- | --- | --- | --- | --- | --- | --- |
| RJ-BLK-001 | local environment | Local restore/build/test and executable-level CLI verification | The current engineering session has no mounted/exposed repository checkout with an executable .NET SDK/runtime surface | Local compilation and runtime test outcomes cannot be classified PASS/FAIL | GitHub-side static review, source edits, test definitions, documentation and remote evidence inspection | Expose or mount the RJ checkout in an environment with the repository-required .NET SDK so restore/build/tests/CLI commands can execute |
| RJ-BLK-002 | GitHub Actions runner provisioning | Remote workflow steps, including build-test | Repeated CI runs fail in `runner-smoke` before the first step; latest observed run `33900445595` has `steps=[]`, `runner_id=0`, and `build-test` is skipped | No remote compilation or test execution is available; workflow conclusion must not be interpreted as a code FAIL | Source review, implementation, test definitions, documentation and CI metadata inspection | `runner-smoke` executes at least its first configured step and produces step/log evidence on a hosted runner |
